# Keestar Restaurant Website

**A clean, minimalist restaurant landing page featuring a delicious menu grid and an interactive contact form.** Built from scratch using semantic HTML5 and custom CSS3 styling.

## 🚀 Features

*   **Custom Brand Header:** Features a navigation menu linking to Home, Recipes, and Contact channels.
*   **Curated Menu Showcase:** Highlights signature dishes complete with high-quality images, interactive description blocks, and responsive order-action elements.
*   **Integrated Communication Form:** Provides an inline "Contact Us" channel featuring input fields for customer reach out.
*   **Card-based Interface Elements:** Employs a structured column layout to isolate and draw attention to individual food items.

---

## 🍽️ Featured Menu

The layout currently highlights three signature culinary offerings:
1.  **French Toast Stack:** Layered artisan French toast dressed with fresh blueberries and sliced bananas.
2.  **Avocado Salad Bowl:** A nutritious greens bowl topped with mixed seeds, fresh avocado mash, and garden vegetables.
3.  **Glazed Chicken Wings:** Crispy, caramelized wings glazed to perfection and garnished with fresh cilantro leaves.

---

## 🛠️ Built With

*   **HTML5:** Semantic elements for structuring content (`<header>`, `<nav>`, form handling).
*   **CSS3:** Document layout design, dark-mode branding styles, typography configuration, and image containment properties.

## 💻 Getting Started

To view and run this project locally on your machine:

1.  **Clone the Repository**
    ```bash
    git clone https://github.com
    ```
2.  **Open the Web Page**
    Navigate into your cloned directory and double-click the `index.html` file to open it directly inside your preferred web browser.
